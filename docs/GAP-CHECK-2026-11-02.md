## 3. Gap Teknis Desain v3 (temuan paling penting)

| # | Item | Detail | Aksi |
|---|---|---|---|
| 3.1 | ⭐ **Idempotency untuk sync offline PWA hilang dari desain** | ROADMAP Fase 2 mensyaratkan draf offline (IndexedDB) → submit saat online. Di jaringan lemah, retry POST tanpa idempotency = **laporan duplikat** (request sampai server, respons tidak sampai browser). Sistem lama sudah solusi: header `Idempotency-Key` + replay respons + `409` bila payload beda (`mobile/lib/core/sync_service.dart:88`, `IdempotencyMiddleware` v1) | Tambahkan ke BLUEPRINT §4.2/§7 dan deliverable+DoD Fase 2 |
| 3.2 | **Strategi antrian & konflik sync offline** | Flutter lama punya `sync_state/retry_count/last_error` (`local_db.dart`); v3 hanya menyebut "draf lokal IndexedDB" tanpa antrian mutasi, retry/backoff, resolusi draf stale vs data server | Definisikan di PRD/ROADMAP Fase 2: antrian per item, backoff eksponensial, flag synced, pembersihan otomatis pasca-sync |
| 3.3 | ⭐ **Sumber data poligon wilayah tidak ada** — TERVERIFIKASI | BLUEPRINT §6 menyebut impor "+ GeoJSON batas wilayah" dari sistem lama, **tetapi sistem lama tidak punya data poligon sama sekali**: 0 file .geojson/.kml/.shp, 0 kolom geometri di dump 45MB | Tentukan sumber eksternal (OSM admin boundaries / Kemendagri / digitisasi manual) + lisensinya. **Prasyarat validasi `ST_Contains` Fase 2** — mulai dicari sejak Fase 1 |
| 3.4 | **Push notifikasi** | Mobile lama = FCM; v3 hanya "notifications in-app" | Putuskan eksplisit: in-app only (rekomendasi Fase 3) vs web push VAPID (opsional Fase 5) |
| 3.5 | **Durasi sesi** | Legacy `SESSION_LIFETIME=28800` (8 jam) + idle timeout; default Laravel 120 menit | Petugas lapangan login sekali sehari → tetapkan sesi panjang di PRD |
| 3.6 | **Reset password** | ROADMAP Fase 1 hanya `POST /auth/reset-password` (admin). Email mandiri butuh SMTP produksi (tidak ada di deliverable Fase 5) | Pilih: admin-only (status quo v1) atau tambah SMTP ke Fase 5 |
| 3.7 | **Quota IndexedDB untuk foto draf** | Foto terkompresi ~100–500 KB × banyak draf; browser quota bervariasi | Batasi jumlah draf + hapus otomatis setelah sync sukses (padanan `photo_synced` Flutter lama) |
